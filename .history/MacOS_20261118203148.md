# macOS 安裝與使用指南

本指南說明如何在 Mac 上安裝 **TUT 琴房空堂批次查詢**。

你可以使用 Chrome、Firefox 或 Safari。以下以 Chrome 與 Tampermonkey 作為主要示範。

## 1. 安裝瀏覽器

可使用以下任一瀏覽器：

- [Google Chrome](https://www.google.com/chrome/)
- [Mozilla Firefox](https://www.mozilla.org/firefox/)
- Safari（macOS 內建）

## 2. 安裝 Userscript 管理器

### Chrome

前往 Chrome 線上應用程式商店安裝：

- [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- [Violentmonkey](https://violentmonkey.github.io/)

### Firefox

前往 Firefox 附加元件網站安裝：

- [Tampermonkey](https://addons.mozilla.org/firefox/addon/tampermonkey/)
- [Violentmonkey](https://addons.mozilla.org/firefox/addon/violentmonkey/)

### Safari

可以使用 [Userscripts](https://apps.apple.com/app/userscripts/id1463298887)。

安裝後，請到 macOS 的 Safari 設定中啟用該擴充功能，並允許它在學校借用系統網站執行。

## 3. 安裝琴房查詢腳本

1. 開啟 [GitHub 專案](https://github.com/yeh0315/TUT-Piano-Room-Loan-System)。
2. 找到 `TUT 琴房空堂批次查詢-3.1.0.txt`。
3. 點選 **Raw**。
4. 複製完整程式碼。
5. 點選瀏覽器工具列中的 Tampermonkey 或 Violentmonkey 圖示。
6. 開啟管理面板，新增一個 Userscript。
7. 刪除編輯器內原本的範例程式碼。
8. 貼上剛才複製的完整程式碼。
9. 儲存並確認腳本已啟用。

若使用 Safari，請依照 Userscripts App 的方式建立 `.user.js` 檔案。

## 4. 開始使用

1. 開啟 [台南應用科技大學琴房借用系統](https://booking.tut.edu.tw/msc/Booking/Booking.aspx)。
2. 選擇「琴房」類別。
3. 等待課表載入。
4. 確認畫面左側出現「琴房空堂批次查詢」面板。
5. 選擇日期與節次。
6. 點選「搜尋所有琴房」。
7. 查看查詢結果，點選想使用的琴房旁的「前往預約頁面」。

## 5. 常見問題

### 沒有出現查詢面板

- 確認 Userscript 管理器已安裝並啟用。
- 確認腳本沒有被停用。
- 確認目前頁面是學校的 Booking.aspx 頁面。
- 確認已經選擇「琴房」並載入課表。
- 重新整理頁面。

### 查詢時出現錯誤

請先確認學校網站可以正常使用，並確認登入狀態沒有逾時。若仍然失敗，可能是學校系統更新造成的相容性問題。

---

**注意事項**

- 本腳本只會查詢各琴房的可預約時段。
- 不會自動預約，也不會代替使用者送出申請。
- 最終預約狀態以學校借用系統顯示為準。
