# Windows / Linux 安裝與使用指南

本指南適用於 Windows 與 Linux 桌面使用者，包含 Chrome、Edge、Firefox、Brave 等支援擴充功能的瀏覽器。

## 1. 安裝瀏覽器

可以使用以下任一支援擴充功能的瀏覽器：

- [Google Chrome](https://www.google.com/chrome/)
- [Microsoft Edge](https://www.microsoft.com/edge)
- [Mozilla Firefox](https://www.mozilla.org/firefox/)
- [Brave](https://brave.com/)

## 2. 安裝 Userscript 管理器

建議使用 Tampermonkey 或 Violentmonkey。

### Tampermonkey

- [Chrome / Edge / Brave 等 Chromium 瀏覽器](https://www.tampermonkey.net/)
- [Firefox](https://addons.mozilla.org/firefox/addon/tampermonkey/)

### Violentmonkey

- [官方網站](https://violentmonkey.github.io/)
- [Firefox 附加元件](https://addons.mozilla.org/firefox/addon/violentmonkey/)

安裝完成後，確認瀏覽器工具列出現 Userscript 管理器圖示。

## 3. 安裝琴房查詢腳本

1. 開啟 [GitHub 專案](https://github.com/yeh0315/TUT-Piano-Room-Loan-System)。
2. 找到 `TUT 琴房空堂批次查詢-3.1.0.txt`。
3. 點選 **Raw**。
4. 複製整份程式碼。
5. 點選瀏覽器工具列上的 Tampermonkey 或 Violentmonkey 圖示。
6. 開啟管理面板。
7. 新增一個 Userscript。
8. 刪除原本編輯器內的範例內容。
9. 貼上完整程式碼。
10. 儲存並確認腳本已啟用。

## 4. 開始使用

1. 開啟 [台南應用科技大學琴房借用系統](https://booking.tut.edu.tw/msc/Booking/Booking.aspx)。
2. 在網站中選擇「琴房」類別。
3. 等待琴房課表載入。
4. 畫面左側應該會出現琴房空堂批次查詢面板。
5. 選擇日期與節次。
6. 點選「搜尋所有琴房」。
7. 等待查詢完成。
8. 從結果中選擇想使用的琴房，點選「前往預約頁面」。

## 5. 常見問題

### 查詢面板沒有出現

請依序確認：

- Userscript 管理器已啟用。
- 腳本已啟用。
- 網址符合學校琴房借用系統的頁面。
- 已選擇「琴房」類別。
- 課表已經載入完成。

完成後重新整理頁面。

### 查詢結果不正確或部分琴房查詢失敗

可能原因：

- 學校網站暫時無法連線。
- 登入狀態逾時。
- 網站更新了課表或查詢機制。
- 網路連線不穩定。

可以重新整理頁面並再次查詢。

---

**注意事項**

- 本腳本僅用於批次查詢琴房空堂。
- 不會自動送出預約。
- 使用者仍須自行確認預約資訊並完成學校系統的預約流程。
