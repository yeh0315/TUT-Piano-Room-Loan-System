# iOS 安裝與使用指南

本指南說明如何在 iPhone 或 iPad 上，透過 Safari 使用 **TUT 琴房空堂批次查詢**。

## 1. 安裝 Safari Userscript 管理器

iOS 上可以使用 [Userscripts](https://apps.apple.com/app/userscripts/id1463298887)。

官方專案：[GitHub - Userscripts](https://github.com/quoid/userscripts)

安裝完成後，依照 App 內的指示設定 Userscripts 的腳本儲存資料夾。

## 2. 啟用 Safari 擴充功能

1. 開啟 iPhone 或 iPad 的「設定」。
2. 進入「App」→「Safari」→「擴充功能」。
3. 找到 Userscripts。
4. 啟用擴充功能。
5. 允許擴充功能在學校借用系統網站上執行。

不同 iOS 版本的設定選單名稱可能略有不同。

## 3. 安裝琴房查詢腳本

1. 開啟 [GitHub 專案](https://github.com/yeh0315/TUT-Piano-Room-Loan-System)。
2. 找到 `TUT 琴房空堂批次查詢-3.1.0.txt`。
3. 點選 **Raw**，開啟原始程式碼。
4. 複製完整程式碼。
5. 開啟 Userscripts App。
6. 在 Userscripts 指定的腳本資料夾中建立新的 `.user.js` 檔案。
7. 將程式碼貼入檔案並儲存。

如果 App 提供直接新增或匯入腳本的功能，也可以使用該功能。

## 4. 開始使用

1. 使用 Safari 開啟 [台南應用科技大學琴房借用系統](https://booking.tut.edu.tw/msc/Booking/Booking.aspx)。
2. 在網站中選擇「琴房」類別。
3. 等待課表載入。
4. 確認 Safari 已允許 Userscripts 在此網站執行。
5. 畫面左側應該會出現琴房空堂查詢面板。
6. 選擇日期與節次，點選「搜尋所有琴房」。

## 5. 常見問題

### 查詢面板沒有出現

- 確認 Safari 已啟用 Userscripts。
- 確認 Userscripts 的網站權限允許此網站執行腳本。
- 確認腳本已放在正確的 Userscripts 資料夾。
- 確認腳本檔案使用 `.user.js` 副檔名。
- 重新整理網站後再試一次。

### iPad 可以使用嗎？

原則上可以使用相同的 Safari 與 Userscripts 安裝方式，但實際顯示效果仍可能因 iPadOS 版本與螢幕尺寸而不同。

**注意事項**

- 預約仍須由使用者自行前往學校系統操作。
- iOS 版本與 Safari 擴充功能的相容性可能影響實際使用結果。
