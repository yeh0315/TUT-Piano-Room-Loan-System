# MacOS 安裝與使用指南

本指南說明如何在 Mac 上安裝及使用 **TUT 琴房空堂批次查詢**。

你可以使用 Chrome、Firefox 或 Safari。

## 1. 安裝必要工具

### 瀏覽器

- [Google Chrome](https://www.google.com/chrome/)
- [Mozilla Firefox](https://www.mozilla.org/firefox/)
- Safari（macOS 內建）

### Userscript 管理器

依照使用的瀏覽器選擇：

| 瀏覽器 | 建議管理器 |
|---|---|
| Chrome | Tampermonkey |
| Firefox | Tampermonkey / Violentmonkey |
| Safari | Userscripts |

下載連結：

- [Tampermonkey](https://www.tampermonkey.net/)
- [Violentmonkey](https://violentmonkey.github.io/)
- [Userscripts for Safari](https://apps.apple.com/app/userscripts/id1463298887)

### Safari 使用者

安裝 Userscripts 後：

1. 開啟 Userscripts App。
2. 確認腳本儲存資料夾已設定。
3. 開啟 Safari 設定。
4. 進入「擴充功能」。
5. 啟用 Userscripts，並允許它在學校借用系統網站執行。

---

## 2. 安裝琴房查詢腳本

有兩種安裝方式，建議優先使用方式 A。

### 方式 A：使用 `.user.js` 直接安裝（推薦）

#### Chrome / Firefox

1. 開啟 [GitHub 專案](https://github.com/yeh0315/TUT-Piano-Room-Loan-System)。
2. 找到名稱以 `.user.js` 結尾的腳本檔案。
3. 點進檔案，點選 **Raw**。
4. 瀏覽器應該會交由 Tampermonkey 或 Violentmonkey 處理。
5. 確認腳本資訊。
6. 點選「安裝」。

#### Safari

1. 使用 Safari 開啟 GitHub 專案。
2. 找到 `.user.js` 檔案並點選 **Raw**。
3. 開啟 Safari 的 Userscripts 擴充功能。
4. 確認出現安裝提示。
5. 點選安裝。

### 方式 B：使用 `.txt` 複製貼上

#### Chrome / Firefox

1. 開啟 [GitHub 專案](https://github.com/yeh0315/TUT-Piano-Room-Loan-System)。
2. 找到 `.txt` 結尾的腳本檔案。
3. 點選 **Raw**。
4. 複製完整程式碼。
5. 開啟 Tampermonkey 或 Violentmonkey 管理面板。
6. 選擇「新增腳本」。
7. 刪除原本的範例內容。
8. 貼上完整程式碼。
9. 儲存並確認腳本已啟用。

#### Safari

1. 使用 Safari 開啟 `.txt` 檔案的 Raw 網址。
2. 複製完整程式碼。
3. 在 Userscripts 的腳本資料夾中建立新的 `.user.js` 檔案。
4. 貼上程式碼並儲存。
5. 重新開啟 Userscripts 擴充功能，確認腳本已載入。

## 3. Chrome / Edge 額外設定

如果使用新版 Chromium 瀏覽器，可能需要允許 Userscript 執行。

1. 在網址列輸入 `chrome://extensions`。
2. 找到 Tampermonkey。
3. 點選「詳細資料」。
4. 開啟「允許使用者指令碼」（Allow user scripts）。

Edge 使用者可以前往 `edge://extensions` 設定。

---

## 4. 開始使用

1. 開啟[台南應用科技大學琴房借用系統](https://booking.tut.edu.tw/msc/Booking/Booking.aspx)。
2. 選擇「琴房」類別。
3. 等待課表載入。
4. 確認畫面左側出現琴房空堂批次查詢面板。
5. 選擇日期與節次。
6. 點選「搜尋所有琴房」。
7. 查看查詢結果並自行前往預約頁面。

---

## 5. 常見問題

### 查詢面板沒有出現

- 確認 Userscript 管理器已啟用。
- 確認腳本已啟用。
- 確認瀏覽器有權限執行 Userscript。
- 確認已選擇「琴房」並載入課表。
- 重新整理頁面。

### Raw 沒有跳出安裝畫面

請改用方式 B，手動複製 `.txt` 內容並新增腳本。
