# Android 安裝與使用指南

本指南說明如何在 Android 手機上安裝 **TUT 琴房空堂批次查詢**。

## 1. 安裝瀏覽器

建議使用支援擴充功能的 Firefox。

- [Firefox for Android](https://www.mozilla.org/firefox/browsers/mobile/android/)

## 2. 安裝 Userscript 管理器

在 Firefox 附加元件中搜尋並安裝以下其中一種：

- [Tampermonkey](https://addons.mozilla.org/firefox/addon/tampermonkey/)
- [Violentmonkey](https://addons.mozilla.org/firefox/addon/violentmonkey/)

安裝完成後，確認擴充功能已啟用。

## 3. 安裝琴房查詢腳本

1. 開啟 [GitHub 專案](https://github.com/yeh0315/TUT-Piano-Room-Loan-System)。
2. 找到 `TUT 琴房空堂批次查詢-3.1.0.txt`。
3. 點選檔案，再點選 **Raw**。
4. 複製整份程式碼。
5. 開啟 Tampermonkey 或 Violentmonkey 的管理介面。
6. 新增一個 Userscript。
7. 將原本的範例內容全部刪除，貼上剛才複製的程式碼。
8. 儲存並確認腳本已啟用。

## 4. 開始使用

1. 開啟 [台南應用科技大學琴房借用系統](https://booking.tut.edu.tw/msc/Booking/Booking.aspx)。
2. 在網站中選擇「琴房」類別。
3. 等待琴房課表載入。
4. 畫面左側應該會出現「琴房空堂批次查詢」面板。
5. 選擇日期與節次。
6. 點選「搜尋所有琴房」。
7. 等待查詢完成，即可查看可預約的琴房。

## 5. 常見問題

### 沒有出現查詢面板

- 確認 Userscript 管理器已啟用。
- 確認腳本本身已啟用。
- 確認目前網址是琴房借用系統的 Booking.aspx 頁面。
- 先在網站中選擇「琴房」，再等待課表載入。
- 重新整理頁面後再試一次。

### 手機畫面顯示不完整

查詢面板固定在畫面左側，若手機螢幕較窄，可以嘗試縮放網頁或切換橫向畫面。

### 查詢失敗

可能是登入狀態逾時、網站暫時無法回應，或網站系統更新。請重新登入並重新整理頁面。

---

**注意事項**

- 本腳本只負責查詢琴房空堂。
- 不會自動送出預約。
- 查詢結果中的「前往預約頁面」會開啟學校原本的預約頁面。
- 實際預約仍須由使用者自行確認與操作。
